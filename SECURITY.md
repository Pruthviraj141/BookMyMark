# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Security is a paramount priority for **BookMyMark**.

If you discover a security vulnerability within this repository or application, please **do not** open a public issue.

Instead, please report the vulnerability privately by emailing:
- **pruthvigavhane@gmail.com**

Please provide:
- A detailed description of the vulnerability.
- Steps or a proof-of-concept to reproduce the behavior.
- Potential impact and affected components.

We will acknowledge receipt within 48 hours and work diligently to release a patch promptly.
